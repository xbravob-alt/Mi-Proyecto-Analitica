## 🎯 Caso de Estudio: Predicción de Entregas Tardías en Olist
Este proyecto aborda la predicción y prevención del riesgo de retrasos logísticos en entregas de comercio electrónico utilizando el dataset público de **Olist** (Brasil). El objetivo es identificar, desde el momento de confirmación de pago, qué pedidos presentan mayor probabilidad de entrega tardía (`is_late = 1`) para respaldar decisiones operativas de negocio.
